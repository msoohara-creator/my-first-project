# ミミドク 🎧

audiobook.jp と Audible の「次に聴く」リストを見える化し、1日1回の耳読書を習慣にするためのアプリです。
サーバー不要の静的Webアプリ（PWA）で、データは端末のブラウザ内だけに保存されます。

## できること

- **次に聴くリスト**: 2つのサービスの本を1本のリストにまとめ、聴く順に並べ替え。サービス別の絞り込み、聴了の記録。
- **今日**: 目標分数に対する進み具合、いま聴いている本の進捗、ワンタップ記録（+5 / +15 / +30分）、連続日数。
- **記録**: 直近17週間のヒートマップ、累計時間、サービス別の積読残り時間と「このペースならいつ聴き終わるか」の見通し。
- **リマインダー**: 指定時刻にまだ聴いていなければ通知。Googleカレンダー / .ics への毎日の予定登録。
- **共有から追加（Android）**: ホーム画面に追加後、作品ページを「共有」→「ミミドク」で追加フォームに自動入力。
- データの書き出し / 読み込み（JSON）、オフライン動作。

## 動かし方

```sh
python3 -m http.server 8000   # → http://localhost:8000 を開く
```

スマホで使うには GitHub Pages などHTTPSで配信できる場所に置き、ブラウザのメニューから「ホーム画面に追加」してください。

## 制限

- audiobook.jp / Audible には公開APIがないため、ライブラリやウィッシュリストの自動取り込みはできません。本はURL貼り付け・共有・手入力で追加します。
- アプリ内通知は、アプリが開いているか裏で動いているときだけ届きます。確実なリマインドにはカレンダー登録を使ってください。
