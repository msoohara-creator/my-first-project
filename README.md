# ブレインロット九九バトル

小学2年生が九九を覚えるための、ブラウザで動くゲームです。
イタリアン・ブレインロットのキャラクターと九九でバトルして、勝つと「ずかん」に仲間が増えていきます。

## あそびかた

`index.html` をブラウザ（Safari / Chrome / Edge など）で開くだけで動きます。インストールは不要です。
iPad・スマホ・パソコンのどれでも遊べます（パソコンではキーボードの数字キーと Enter でも答えられます）。

| メニュー | できること |
| --- | --- |
| **バトル** | 段を選んでキャラクターと対戦。正解すると答えの数字が飛んでいってダメージ。まちがえた問題はもう一度出ます |
| **おぼえる** | 段ごとに九九の唱え方（「さんし じゅうに」など）を読み上げ。「1さらに ○こずつ」の絵で意味もわかります |
| **ずかん** | 倒したキャラクターが仲間になって集まります。★3つ（まちがい0）でキラキラに |
| **きろく** | 81問それぞれの「おぼえた／れんしゅう中／にがて」を色で表示（おうちの方向けの説明つき） |

- 問題の順番は **のぼり（上がり九九）／くだり（下がり九九）／バラバラ** から選べます
- 「ミックス」は全部の段から15問。ラスボスが登場します
- 「にがて とっくん」は、まちがえた九九だけを集中練習します
- 記録はその端末のブラウザ（localStorage）に保存されます

## メモ

- 1ファイル（`index.html`）だけで完結しています。フォントは Google Fonts から読み込みます（オフラインでも端末のフォントで動きます）
- 読み上げはブラウザの音声合成を使います。iPhone / iPad で音が出ないときは消音スイッチを確認してください
